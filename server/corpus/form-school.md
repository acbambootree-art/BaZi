## 氣乘風則散 | tags: FM-CORRIDOR FM-DOORLINE 穿堂 風水 | type: quote
氣乘風則散，界水則止。古人聚之使不散，行之使有止，故謂之風水。（葬書）

## 穿堂煞 | tags: FM-CORRIDOR 穿堂煞 | type: note
大門直對窗、後門或長走廊，氣入即出，謂之穿堂煞，主財不聚。以玄關、屏風、矮櫃使氣迴旋。

## 橫樑壓頂 | tags: FM-BEAM 橫樑 | type: note
床、座位、灶上有橫樑直壓，主頭痛、壓力、不安。宜移床避之；不能移者以假天花或床帳遮之。

## 鏡照床 | tags: FM-MIRROR 鏡 | type: note
鏡對床主睡不安穩、夫妻口舌。移去或夜間遮蓋。

## 門沖床 | tags: FM-DOORLINE 門沖 | type: note
床與門成一直線為門沖，氣直衝床身。宜移床至見門而不對門之位（指揮位）。

## 廁門對門 | tags: FM-TOILET 廁所 | type: note
大門或房門對廁所門，穢氣相沖。常閉廁門，加門簾或屏風。

## 灶對水 | tags: FM-STOVE 灶 水火 | type: note
灶對水槽、冰箱為水火相沖。宜移位；不能移者以木（木板、植物）通關。

## 尖角沖射 | tags: FM-CORNER 尖角 | type: note
牆角、櫃角尖射床位或座位為尖角煞。移位或以植物、布幔化其鋒。
